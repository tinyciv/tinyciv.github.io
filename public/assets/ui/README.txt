HUD source artwork supplied by the project owner. The PNGs are unchanged copies of rts-minimap-leader-panels-redesign.png and rts-resource-bar-redesign.png. CSS uses their source regions directly; resource-texture.svg wraps an embedded copy of the resource reference to reuse its empty slate panel, including a #slate view. Dynamic values, fog, portraits and five-section health bars are rendered above the artwork. Game terrain and entities continue to use Puny World and Puny Characters.

village-alliance.png is the retired 28×18 transparent handshake marker, generated with built-in ImageGen and exported with nearest-neighbor sampling. The prompt, original image, and export coordinates are in scratch/2026-10-31-village-alliance-icon. The game now draws a white pixel checkmark directly in src/game/village-marker.ts, with the white warning markers' ivory fill and warm dark outline; the handshake PNG is no longer loaded.

city-panel-walnut.png is the selected 1A walnut-and-iron city-name frame, generated with built-in ImageGen using the existing HUD as reference. It is an unchanged 103×20 RGBA export from scratch/2026-10-31-city-panels/panels-ab/assets/1A.png; prompts and uniform-grid export provenance are in that proposal folder. It is preloaded before city labels are cached. Native pixels render at 2×, with fixed corner insets [6,5,6,5] and repeated/cropped straight regions. Names and statistics remain live text; owned labels are 40px high and foreign name-only labels 28px.

forged/ contains the approved Forged Citadel HUD artwork generated with built-in Imagegen from the final concept in scratch/2026-10-31-tight-build-hud. The minimap and hotbar frames have transparency; panel-frame.png supplies the reusable slate/brass surface; action-symbols.png is the 2×2 hammer, stone wall, machete and forbid atlas. All text, keyboard hints, game values and portraits remain live. Generation prompts, source paths, dimensions and alpha metadata are recorded in forged/manifest.json and scratch/2026-10-31-hud-implementation/art/.

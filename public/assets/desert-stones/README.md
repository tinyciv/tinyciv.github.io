# Desert stones (8FC)

24 individual ochre stones extracted from `../lpc-rocks/rocks.png`, the upper loose-stone row at y=896. Original pixels and colors are preserved; the game draws them at 2× with nearest-neighbor sampling. `source.json` records original source rectangles. Empty 16×16 cells pad each feature at its top-left; see `src/game/desert-stone-art.ts` for visible sizes.

Source: LPC Rocks, bluecarrot16 and contributors. These crops retain the source's CC BY-SA 4.0 license and attribution; see the bundled `../lpc-rocks/` license/credits files. No generated artwork.

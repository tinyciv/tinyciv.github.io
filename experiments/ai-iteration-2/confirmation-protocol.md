# Independent confirmation protocol

Finalized before independent confirmation begins. Screening and search confirmation data may select candidates; the final seed family below is reserved for a separate evaluation.

Select the search incumbent if a challenger was promoted. Otherwise take the challenger with the largest positive-minus-negative seed count in the search confirmation stages (ties favor the lower sign-test p-value). If every challenger has a nonpositive count, take the highest eligible non-control policy from the last complete generation's screening standings. This selection rule uses training evidence only. Also retain field-concentration, the strongest initial human hypothesis, if it is a different genome. Export full resolved settings and rules, rather than mutable references to optimizer parents.

Evaluate the selected finalist(s), hard-assault, and expansionist in a complete mirrored round robin: 24 new seeds, field-battle, 240 simulated seconds. The seed family is `iteration-2-independent-final`. For each finalist/control comparison, combine both legs by seed. Report wins/draws/losses, positive/negative/tied seeds, and an exact one-sided sign test. Apply a Bonferroni threshold of 0.05 divided by the number of finalist/control comparisons. No outcome score converts timeouts to wins. No final-validation-driven parameter edits.

Additional transfer checks use the same frozen engine: fixed opponents (`sim ai`, 90 seconds, three scenarios and three seeds), a fortified match check, and a paired 3600-second default-world case study. These checks diagnose regressions; they do not establish general economic or siege superiority. A single generated map is a case study, not independent statistical confirmation.

The live default is not changed by this experiment. Publish the best supported experimental policy and all limitations, including a null result if no stronger candidate is confirmed.

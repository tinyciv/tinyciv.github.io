01 · Headwaters

A ribbon inside the tile.

2–7 pixels wide on a 16-pixel tile. Ground remains on both sides. Walkers can cross anywhere, with a proposed small movement penalty. No ford is required.

0 < Q < 64

02 · Tributaries

One tile, frequent fords.

One full water tile across ordinary reaches. Walkers use complete bank-to-bank fords, roughly every 6–10 channel tiles where the banks fit. Each tributary gets its own crossings.

64 ≤ Q < 640
1 tile · ford crossing only
03 · Main river

The tributaries add up.

2–5 tiles wide as combined discharge grows. Broad reaches become meaningful barriers. Find a complete ford or build a bridge; deep channels do not get decorative stepping stones.

Q ≥ 640
width = min(5, 2√(Q / 640))

One network, from the source.

  1. Give each catchment cell one downstream receiver. Resolve depressions and lake spillways first, then sum rainfall runoff from every contributing cell.
  2. Expose the small feeders. Trace headwater branches into the shared drainage network. Nested tributaries merge into existing channels all the way to the outlet.
  3. Vary bends along the channel. Small streams wind around local terrain; tributaries alternate tighter bends with quiet stretches; broad rivers make larger lateral sweeps. Bend size and spacing vary independently.
  4. Size water from accumulated discharge. At a junction, outgoing Q equals incoming Q plus local runoff. The same width rule applies across the entire basin.
  5. Place crossings along each reach. Prefer straight, shallow, one-tile sections with accessible opposite banks. Keep junctions clear, and measure gaps along the channel.
  6. Check actual movement. Stream ribbons remain ground. Full water cells block walking except at complete fords. A route through a cliff, partial ford, or deep river is invalid.

This prototype computes runoff and walkable routes on a seeded, nested tributary plan. In the game, that plan would come from the existing terrain drainage and lake-outlet system. The discharge thresholds are proposed gameplay values, not calibrated measurements.

The current generator already accumulates runoff. The main changes are to expose many small headwaters, add a separate stream layer, remove the minimum wide-channel footprint, and distribute fords along individual tributaries.

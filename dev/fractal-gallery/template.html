How to compare these worlds

Each sample uses the same terrain seed and a different reproducible random combination of all landscape controls. Values are spread across each control’s review range so the collection covers more than one typical setting. Changing the seed makes a fresh collection. Stars mark favorites in this browser; exporting a sample saves its exact seed and settings for reproduction.

Map percentages measure dry land. Desert excludes sandy beaches. Spacing measures the closest pair of faction capitals; small matching dots mark a faction’s second city. The dashed equator guide shows the center of the warm belt, not a hard biome boundary. All maps use the real game generator and preserve the same movement rules.
